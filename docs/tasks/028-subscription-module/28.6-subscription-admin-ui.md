# Task 28.6 — Subscription Administration UI

## Status

Complete.

## Objective

Provide administration screens for plans, subscriptions, entitlements, and limits.

## Scope

Implement:

* Plans Screen
* Subscription Screen
* Entitlements Screen
* Usage Limits Screen
* Trial Management Screen

## Authorization

Requires:

* SUPER_ADMIN

Tenant visibility:

* TENANT_ADMIN may view own subscription.

## Completion Criteria

* Plans manageable.
* Subscriptions manageable.
* Entitlements visible.
* Limits visible.
* Trials manageable.

## Implementation Summary

Task 28.6 adds shared Flutter contracts and admin UI over the backend APIs from
Tasks 28.1 through 28.5.

Implemented:

* Shared subscription models in `packages/shared_models`
* Typed subscription API service in `packages/api_client`
* Admin subscription repository and Riverpod providers
* Subscription Administration navigation entry
* Plans tab for plan creation, activation, deactivation, feature replacement,
  and version inspection
* Subscription tab for tenant subscription visibility, lifecycle history,
  activation, plan changes, and status transitions
* Entitlements tab for effective entitlement visibility, platform overrides,
  and revocation
* Usage tab for tenant usage counter visibility and reconciliation
* Trials tab for trial start, extension, expiry, conversion, and due-expiry
  processing

Tenant admins can view their authenticated tenant scope. Platform
administrators can enter a tenant ID and perform mutations. Backend
authorization remains authoritative.
