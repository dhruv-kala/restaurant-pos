# Task 28.1 - Plan Management

## Status

Complete.

## Objective

Provide SaaS plan administration.

## Scope

Implemented:

* SubscriptionPlan
* SubscriptionPlanFeature
* create plan
* update plan
* activate/deactivate plan
* plan versioning foundation

## Invariants

* Plans are platform managed.
* Tenant users cannot modify plans.
* Historical subscriptions retain original plan references.

## Implemented Contract

* Plans are global platform catalog records and do not carry tenant scope.
* A plan code is stable across immutable numbered versions.
* New plans start as draft version 1.
* Draft versions can be edited in place with optimistic concurrency.
* Editing an activated or deactivated version creates the next draft version
  and copies its feature snapshot.
* Activating a draft automatically deactivates the prior active version for
  the same code.
* Only one active version may exist for a plan code.
* Feature replacement is allowed only while a version remains draft.
* Activated plan fields and feature snapshots are protected by PostgreSQL
  triggers.
* Plan and feature references use restrictive deletion behavior.
* Create, update, version creation, feature replacement, activation, and
  deactivation append platform audit events.

## Completion Criteria

* Plans can be created.
* Features can be assigned to plans.
* Audit events are generated.
