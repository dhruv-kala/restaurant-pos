# Task 28.5 — Trial Management

## Status

Planned.

## Objective

Provide tenant trial subscriptions.

## Scope

Implement:

* TrialSubscription

Features:

* start trial
* extend trial
* expire trial
* convert to paid subscription

## Invariants

* Trial periods are time-bound.
* Expired trials lose access according to entitlement rules.
* Trial history remains immutable.

## Completion Criteria

* Trial lifecycle operational.
* Expiry handling operational.
* Audit events generated.
