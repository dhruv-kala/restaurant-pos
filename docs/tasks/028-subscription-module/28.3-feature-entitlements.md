# Task 28.3 — Feature Entitlements

## Status

Planned.

## Objective

Control feature availability by subscription.

## Scope

Implement:

* TenantEntitlement

Examples:

* inventory access
* communication access
* loyalty access
* customer app access
* API access

## Invariants

* Features are resolved through entitlement evaluation.
* Business modules must not bypass entitlement checks.

## Completion Criteria

* Entitlement evaluation service operational.
* Feature access enforced.
* Audit events generated.
