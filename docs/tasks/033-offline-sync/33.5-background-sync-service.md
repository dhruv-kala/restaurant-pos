# Task 33.5 - Background Sync Service

Status: Complete.

## Objective

Synchronize local changes automatically.

## Scope

Implemented:

* background sync worker foundation
* injected sync transport abstraction
* bounded exponential retry policy
* retryable queue claiming
* queue success, retry, failed, and conflict transitions
* sync batch history
* checkpoint tracking
* device sync state counter refresh

## Invariants

* Synchronization is idempotent through stable queue item idempotency keys.
* Retries are bounded by `OfflineSyncRetryPolicy.maxAttempts`.
* Failed synchronization never deletes queue records.
* Conflicts remain routed through the Task 33.4 conflict foundation.
* Checkpoints are scoped by tenant, outlet, device, and module.
