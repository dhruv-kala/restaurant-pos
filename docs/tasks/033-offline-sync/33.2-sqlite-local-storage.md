# Task 33.2 - SQLite Local Storage

Status: Complete.

## Objective

Create local SQLite persistence.

## Scope

Implemented:

* SQLite schema
* local repositories
* local entity mapping

Support:

* Orders
* Bills
* Customers
* Inventory

## Invariants

* Local IDs remain globally unique.
* Tenant and outlet scope are preserved.
* Device scope is preserved for local projections.
* Source payload JSON is retained so future sync tasks can avoid lossy
  projection changes.

## Implementation Notes

Implemented in `apps/restaurant-app/lib/core/offline`:

* `OfflineLocalDatabase` opens a durable SQLite database and creates schema
  version 1.
* `device_sync_state` stores the Task 33.1 `DeviceSyncState` contract.
* `local_orders`, `local_bills`, `local_customers`, and
  `local_inventory_items` store scoped local projections with source payload
  JSON and dirty flags.
* `OfflineEntityMapper` converts between SQLite rows and local Dart
  projections.
* `OfflineLocalRepository` exposes scoped upsert, get, and list methods.

## Completion Criteria

* Local storage operational.
* Data persists across restarts.
