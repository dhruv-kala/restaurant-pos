# Task 33.4 - Conflict Resolution Engine

Status: Complete.

## Objective

Handle synchronization conflicts safely.

## Scope

Implemented:

* `sync_conflicts` SQLite table
* append-only `sync_conflict_decisions` SQLite table
* conflict detection that marks affected queue items as `CONFLICT`
* server-wins resolution
* client-wins resolution
* manual-review routing
* financial-record manual-review enforcement

## Supported Decisions

* Server wins: maps to `SERVER_AUTHORITY`, marks the queue item `SUCCESS`.
* Client wins: maps to `LAST_WRITE_WINS`, returns the queue item to `PENDING`.
* Manual review: maps to `MANUAL_REVIEW`, keeps the conflict open and queue
  item in `CONFLICT`.

## Invariants

* Financial records never silently overwrite.
* Conflict rows are preserved.
* Every resolution decision is recorded in append-only decision history.
* Tenant, outlet, device, queue item, entity, local payload, and server payload
  context are preserved.

* Conflict resolution works.
