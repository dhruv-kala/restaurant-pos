# Task 33.6 - Offline POS Operations

Status: Complete.

## Objective

Enable offline restaurant POS operations.

## Scope

Supported:

* Orders
* Bills
* Payments
* Receipts

## Implemented

* local payment and receipt projection tables
* `OfflinePosOperationsService`
* offline order creation
* offline order status updates
* offline bill generation
* offline manual payment recording
* offline receipt generation
* atomic local projection plus sync queue/change-log writes
* local bill paid-state updates after payment

## Invariants

* Business workflows remain operational offline.
* Financial records remain auditable.
* Every offline POS command uses stable local IDs and idempotency keys.
* Local projection and queued command writes are transactional.
* Payments require an existing local bill.
* Receipts require an existing local bill.

## Completion Criteria

* POS works offline at the operation-service foundation level.
* Synchronization can continue after reconnect through queued commands.

## Validation

* `flutter analyze` from `apps/restaurant-app` passed.
* `flutter test test/core/offline` from `apps/restaurant-app` passed.
