# Task 33.8 - Sync Monitoring and Recovery

Status: Complete.

## Objective

Provide visibility into synchronization health.

## Scope

Implement:

* SyncBatch visibility
* SyncCheckpoint visibility

Features:

* Retry visibility
* Failure visibility
* Stale in-progress visibility
* Recovery tools

## Completion Criteria

* Sync health visible. Complete.
* Recovery operational. Complete.

## Implemented Scope

* Added local sync health snapshots for queue counts, failed items, retrying
  items, stale in-progress items, open conflicts, recent batches, checkpoints,
  and device sync state.
* Added repository queries for queue state counts, multi-state queue listings,
  and checkpoint listings.
* Added recovery operation to retry failed and retrying queue items.
* Added recovery operation to move stale in-progress queue items back to
  retrying.
* Added tests for monitoring visibility and recovery behavior.
