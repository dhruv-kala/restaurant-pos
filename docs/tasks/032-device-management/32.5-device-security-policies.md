# Task 32.5 - Device Security Policies

## Status

Complete.

## Objective

Provide device-level security controls.

## Scope

Implement:

* `DeviceSecurityPolicy`

Features:

* trusted device requirement
* session timeout
* forced logout
* device restrictions

## Invariants

* Policies are tenant scoped.
* Outlet overrides are supported.
* Security changes are auditable.
* One active policy is allowed per tenant/outlet scope.
* Outlet-scoped policies override tenant-wide policies.
* Policies are not hard deleted.

## Completion Criteria

* Security policies operational - complete.
* Policy enforcement operational - complete for session timeout, device-type
  restrictions, forced logout, and effective-policy evaluation.
* Audit events generated - complete.

## Implementation Notes

Task 32.5 added tenant/outlet-scoped device security policies with optimistic
updates, forced RLS, no-delete protection, `devices.security_manage`
authorization, and audit events.

Task 32.5 does not add Flutter UI or shared Dart clients. Those remain part of
Task 32.6 Device Administration UI.

Request-level trusted-session guard enforcement is deferred until the platform
has an authenticated device-session token/header contract. Current enforcement
is applied inside trusted-session creation/renewal and exposed through the
effective policy evaluation API.
