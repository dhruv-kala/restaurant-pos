# Task 32.3 - Trusted Sessions

## Status

Complete.

## Objective

Provide trusted device sessions for activated devices.

## Scope

Implemented:

* `TrustedSession`
* trusted login/session creation
* trusted session renewal
* session revocation
* trusted session history and detail APIs

Not implemented in this task:

* terminal assignment
* device security policies
* auth guard enforcement against trusted-session tokens
* Flutter/shared client UI

## Invariants

* Trusted sessions are tenant scoped.
* Trusted sessions belong to exactly one device and one user.
* Session creation binds to the authenticated actor; user ownership is not
  accepted from request payloads.
* Session tokens are returned once and stored only as hashes.
* Sessions are revocable.
* Expired active sessions transition to `EXPIRED`.
* Session renewal and revocation require ownership or device-session management
  authority.
* Trusted-session lifecycle events are auditable.

## Backend

Added protected APIs:

* `POST /devices/:id/trusted-sessions`
* `GET /devices/:id/trusted-sessions`
* `GET /trusted-sessions`
* `GET /trusted-sessions/:id`
* `PATCH /trusted-sessions/:id/renew`
* `PATCH /trusted-sessions/:id/revoke`

Added permission:

* `devices.manage_sessions`

Added audit events:

* `trusted_session.created`
* `trusted_session.renewed`
* `trusted_session.expired`
* `trusted_session.revoked`

## Completion Criteria

* Trusted sessions are operational.
* Session renewal is operational.
* Session revocation is operational.
* Audit events are generated.
* Prisma schema validates.
* NestJS build, lint, and tests pass.
