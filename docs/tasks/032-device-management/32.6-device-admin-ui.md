# Task 32.6 - Device Administration UI

## Status

Complete.

## Objective

Provide administration screens for device operations.

## Scope

Implemented:

* Device list screen
* Device enrollment management
* Trusted session management
* Terminal management
* Device assignment management
* Security policy screen
* Device audit visibility

## Authorization

The admin navigation exposes the module to super admins, tenant admins, and
users with any of:

* `devices.read`
* `devices.register`
* `devices.update_status`
* `devices.enroll`
* `devices.activate`
* `devices.manage_sessions`
* `devices.security_manage`
* `terminals.manage`

Backend authorization remains authoritative.

## Completion Criteria

* Device management UI operational - complete.
* Enrollment management UI operational - complete.
* Security policy UI operational - complete.

## Implementation Notes

Task 32.6 added shared Dart device contracts, a typed device-management API
client, Riverpod repository/provider wiring, and an admin Device Administration
screen.

No backend schema or NestJS controller changes were required because Tasks
32.1-32.5 already supplied the API contracts.
