# Task 32.2 - Device Enrollment and Activation

## Status

Complete.

## Objective

Provide controlled enrollment and activation of registered tenant devices.

## Scope

Implemented:

* `DeviceEnrollment`
* enrollment request
* activation code generation and protected hash storage
* activation approval
* activation workflow
* enrollment history

Not implemented in this task:

* trusted sessions
* terminal assignment
* device security policies
* Flutter/shared client UI

## Invariants

* Enrollment requests are tenant scoped and auditable.
* Activation is tenant scoped and outlet-authorized.
* Activation codes expire.
* Only one `REQUESTED` or `APPROVED` enrollment may exist per device.
* Activation requires an approved, unexpired enrollment.
* Enrollment records are append-only; expiry is a state transition.

## Backend

Added protected APIs:

* `POST /devices/:id/enrollments`
* `GET /devices/:id/enrollments`
* `GET /device-enrollments/:id`
* `PATCH /device-enrollments/:id/approve`
* `POST /device-enrollments/activate`

Added permissions:

* `devices.enroll`
* `devices.activate`

Added audit events:

* `device.enrollment_requested`
* `device.enrollment_approved`
* `device.enrollment_expired`
* `device.enrollment_activated`
* `device.activated`

## Completion Criteria

* Device enrollment works.
* Activation workflow works.
* Audit events are generated.
* Prisma schema validates.
* NestJS build, lint, and focused tests pass.
