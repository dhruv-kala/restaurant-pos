# Task 32.4 - Terminal Management

## Status

Complete.

## Objective

Provide operational terminal management.

## Scope

Implemented:

* `Terminal`
* `DeviceAssignment`
* terminal identity
* outlet-scoped terminal management
* device assignment to terminals
* assignment ending/history

Not implemented in this task:

* device security policies
* terminal UI
* shared Dart clients
* printer/cash drawer peripheral integrations

## Examples

* POS Counter 1
* POS Counter 2
* Kitchen Screen A
* Kitchen Screen B

## Invariants

* Terminals are tenant and outlet scoped.
* Terminal codes are unique per tenant/outlet.
* Device assignments are auditable.
* One active assignment is allowed per terminal.
* One active assignment is allowed per device.
* Assigned devices must be active.
* Assigned devices must belong to the same outlet as the terminal.
* Assignment history is append-only.

## Backend

Added protected APIs:

* `POST /terminals`
* `GET /terminals`
* `GET /terminals/:id`
* `PATCH /terminals/:id`
* `POST /terminals/:id/device-assignments`
* `GET /terminals/:id/device-assignments`
* `GET /device-assignments`
* `PATCH /device-assignments/:id/end`

Added permission:

* `terminals.manage`

Added audit events:

* `terminal.created`
* `terminal.updated`
* `terminal.device_assigned`
* `terminal.device_assignment_ended`

## Completion Criteria

* Terminal management works.
* Device assignment works.
* Audit events are generated.
* Prisma schema validates.
* NestJS build, lint, and tests pass.
