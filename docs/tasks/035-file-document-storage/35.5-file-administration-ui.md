# Task 35.5 - File Administration UI

## Status

Planned.

## Objective

Add admin screens for file visibility, access, retention policy management,
and deletion controls.

## Scope

Implement:

* shared Dart file models
* typed file API client
* Riverpod providers
* admin file list and detail screens
* download/access action
* retention policy screen
* deletion and legal-hold controls

## Deferred

* document preview renderer
* OCR
* bulk archive exports

## Completion Criteria

* Authorized admins can inspect tenant files.
* Retention policies are manageable with tenant/outlet scope.
* UI does not expose permanent public URLs or secrets.
