# Task 35.3 - Upload, Download, and Signed Access

## Status

Planned.

## Objective

Add upload, download, and short-lived signed access workflows for authorized
file content access.

## Scope

Implement:

* upload endpoint using storage abstraction
* file validation by purpose
* checksum persistence on completion
* authorized download endpoint
* `FileAccessGrant` metadata
* short-lived signed token verification
* audit events for access grant creation

## Deferred

* retention purge
* antivirus scanning
* CDN integration
* admin UI

## Completion Criteria

* Unauthorized users cannot download file content.
* Access grants expire.
* Upload failures do not leave active metadata records.
* Sensitive filesystem paths are never exposed.
