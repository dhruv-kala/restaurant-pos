# Task 35.1 - Storage Abstraction Foundation

## Status

Planned.

## Objective

Create a storage-provider abstraction that initially supports local filesystem
storage and preserves a future object-storage option.

## Scope

Implement:

* storage provider interface
* local filesystem provider rooted in configured storage path
* safe path normalization
* checksum calculation
* MIME type and size validation hooks
* configuration contract without committed secrets

## Deferred

* file metadata APIs
* signed access grants
* retention policies
* admin UI

## Completion Criteria

* Files cannot escape the configured storage root.
* Stored bytes return checksum and size metadata.
* Provider can be replaced without business-module changes.
