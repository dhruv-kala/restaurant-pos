# Task 35.4 - Document Retention and Deletion Policies

## Status

Planned.

## Objective

Add tenant default and outlet override retention policies plus safe deletion
and purge controls.

## Scope

Implement:

* `FileRetentionPolicy` schema
* tenant default and outlet override precedence
* legal-hold flag
* deletion request action
* purge eligibility service
* `FileDeletionRecord` history
* protected retention APIs
* audit events

## Deferred

* automated purge scheduler wiring
* UI
* external archive storage

## Completion Criteria

* Legal hold blocks purge.
* Financial/fiscal files cannot be deleted in violation of policy.
* Outlet override behavior is documented and tested.
* Deletion history is retained.
