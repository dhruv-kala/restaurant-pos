# Task 35.2 - File Metadata, Ownership, and Access Control

## Status

Planned.

## Objective

Persist tenant-safe file metadata and ownership rules for files stored through
the storage abstraction.

## Scope

Implement:

* `StoredFile` metadata schema
* `FileReference` business-record link schema
* tenant and optional outlet scope
* purpose classification
* file status lifecycle
* forced RLS
* protected list/detail APIs
* ownership validation service

## Deferred

* upload streaming
* signed downloads
* retention purge
* admin UI

## Completion Criteria

* File metadata is tenant isolated.
* Outlet-scoped file access checks outlet authorization.
* Business references cannot cross tenants.
* Tests cover cross-tenant denial.
