## Correction Applied

The review identified one high-impact design gap:

- Expected tax precedence requires `Item Rule -> Category Rule -> Tenant Default
  Rule`, but Task 30.2 only modeled item and category mappings.

Correction:

- Added `TENANT_DEFAULT` to `TaxMappingTarget`.
- Updated `TaxCategoryMapping` constraints so tenant default mappings require no
  menu category or item target.
- Added target validity indexing for default/category/item mapping lookup.
- Updated service validation and overlap checks for tenant default mappings.
- Added focused schema and service tests.
