# Task 30.6 - Tax Admin UI

## Status

Complete.

## Objective

Provide tenant administrators with tax configuration and fiscal policy
management screens.

## Scope

Implement:

- Tax Profile Screen
- Tax Rate Screen
- Tax Group Screen
- Tax Mapping Screen
- Outlet Fiscal Policy Screen
- Tax Report Screen

Do not implement:

- government filing UI
- accounting export UI
- fiscal device UI

## Ownership

- tax administration
- fiscal policy administration
- tax report visibility

## Screens

### Tax Profiles

Display:

- profile name
- tax mode
- status
- default flag

### Tax Rates

Display:

- tax name
- percentage
- effective dates
- status

### Tax Groups

Display:

- group name
- included rates
- total rate

### Fiscal Policy

Display:

- outlet
- invoice prefix
- fiscal year
- next sequence

### Tax Reports

Display:

- taxable amount
- CGST
- SGST
- IGST
- total tax
- invoice count

## Authorization

Requires one of:

- `tax.read`
- `tax.profile_manage`
- `tax.policy_manage`
- `tax.report_view`
- `fiscal_policy.read`
- `fiscal_policy.manage`

Tenant administrators and super administrators can view the Tax Center.

## Dependencies

Requires:

- Task 30.1
- Task 30.2
- Task 30.3
- Task 30.4
- Task 30.5

## Implementation Summary

- Added shared Dart tax models for profiles, rates, groups, rules, mappings,
  fiscal policies, fiscal sequences, and tax reports.
- Added a typed Dio `TaxApiService` for the existing Task 30.1-30.5 backend
  endpoints.
- Added Riverpod tax providers and an admin Tax Center screen with profile,
  rate, group, mapping, fiscal policy, and report tabs.
- Wired the Tax Center into the admin app navigation behind tenant admin,
  super admin, and tax/fiscal permissions.
- Did not implement government filing, accounting export, or fiscal device UI.

## Completion Criteria

- Tax configuration UI works.
- Fiscal policy UI works.
- Tax reports visible.
- Build passes.
