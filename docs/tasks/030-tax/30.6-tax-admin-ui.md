# Task 30.6 — Tax Admin UI

## Status

Planned.

## Objective

Provide tenant administrators with tax configuration and fiscal policy management screens.

## Scope

Implement:

- Tax Profile Screen
- Tax Rate Screen
- Tax Group Screen
- Tax Mapping Screen
- Outlet Fiscal Policy Screen
- Tax Report Screen

Do not implement:

- government filing UI
- accounting export UI
- fiscal device UI

## Ownership

- tax administration
- fiscal policy administration
- tax report visibility

## Screens

### Tax Profiles

Display:

- profile name
- tax mode
- status
- default flag

### Tax Rates

Display:

- tax name
- percentage
- effective dates
- status

### Tax Groups

Display:

- group name
- included rates
- total rate

### Fiscal Policy

Display:

- outlet
- invoice prefix
- fiscal year
- next sequence

### Tax Reports

Display:

- taxable amount
- CGST
- SGST
- IGST
- total tax
- invoice count

## Authorization

Requires:

- TAX_VIEW
- TAX_POLICY_MANAGE
- FISCAL_POLICY_MANAGE
- TAX_REPORT_VIEW

## Dependencies

Requires:

- Task 30.1
- Task 30.2
- Task 30.3
- Task 30.4
- Task 30.5

## Completion Criteria

- Tax configuration UI works.
- Fiscal policy UI works.
- Tax reports visible.
- Build passes.
