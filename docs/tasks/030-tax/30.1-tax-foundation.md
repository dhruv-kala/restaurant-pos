# Task 30.1 — Tax Foundation

## Status

Planned.

## Objective

Create the base tax domain and shared tax concepts.

## Scope

Implement:

- TaxProfile
- TaxType enums
- TaxMode enums
- basic tenant-scoped tax configuration

Do not implement:

- complex rules
- invoice sequencing
- reports
- admin UI

## Ownership

- base tax profile storage
- tax mode classification
- tenant tax foundation

## Invariants

- Tax profiles are tenant scoped.
- A tenant may have one default active tax profile.
- Tax profiles cannot cross tenant boundaries.
- Historical bills must not depend on live profile values.

## Dependencies

Requires:

- Tenant Management
- RBAC
- Audit
- Billing

## Completion Criteria

- Tax profiles exist.
- Tax profile CRUD works.
- Default tax profile can be resolved.
- Audit events generated.
- Build passes.
