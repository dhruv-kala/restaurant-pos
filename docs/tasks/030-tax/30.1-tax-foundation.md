# Task 30.1 - Tax Foundation

## Status

Complete.

## Objective

Create the base tax domain and shared tax concepts.

## Scope

Implemented:

- TaxProfile
- TaxType enum
- TaxMode enum
- TaxProfileStatus enum
- basic tenant-scoped tax configuration
- default active tax profile resolution
- protected NestJS tax profile APIs
- RBAC permission seeds
- tax profile audit events

Do not implement:

- complex rules
- tax rates
- tax groups
- invoice sequencing
- reports
- admin UI

## Ownership

- base tax profile storage
- tax mode classification
- tenant tax foundation

## Invariants

- Tax profiles are tenant scoped.
- A tenant may have one default active tax profile.
- Tax profiles cannot cross tenant boundaries.
- Historical bills must not depend on live profile values.

## Dependencies

Requires:

- Tenant Management
- RBAC
- Audit
- Billing

## Implementation Notes

- Added `TaxProfile`, `TaxType`, `TaxMode`, and `TaxProfileStatus` to Prisma.
- Added forced RLS and tenant-aware constraints for `tax_profiles`.
- Added a partial unique index so each tenant has at most one active default
  tax profile.
- Added protected NestJS APIs under `/tax/profiles`.
- Added lowercase RBAC permissions: `tax.read`, `tax.profile_manage`,
  `tax.policy_manage`, and `tax.report_view`.
- Added audit events for tax profile creation and updates.
- Tax rates, tax groups, tax rules, fiscal policy, calculation, reports, shared
  Dart clients, and UI remain deferred to later Task 30 subtasks.

## Completion Criteria

- Tax profiles exist.
- Tax profile CRUD works.
- Default tax profile can be resolved.
- Audit events generated.
- Build passes.
