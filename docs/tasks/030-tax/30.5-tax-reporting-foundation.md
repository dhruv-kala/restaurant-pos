# Task 30.5 - Tax Reporting Foundation

## Status

Complete.

## Objective

Provide tax reporting APIs for GST/VAT summaries and detailed tax breakdowns.

## Scope

Implemented:

- tax summary report
- detailed tax report
- invoice count report
- taxable amount report

Not implemented:

- tax return filing
- government submission
- accounting export
- tax admin UI
- shared Flutter clients

## Ownership

- tax report aggregation
- businessDate-based reporting
- outlet tax summaries

## Reports

- Tax Summary
- GST Summary
- Taxable Sales
- Tax Collected
- Invoice Tax Detail

## Invariants

- Reports use bill and tax calculation snapshots.
- Reports use `businessDate`.
- Reports do not recalculate historical tax from current rules.
- Tenant isolation is enforced.

## Dependencies

Requires:

- Task 30.4
- Billing
- Receipts
- Reports Module

## Implementation Summary

- Added protected `GET /tax/reports/summary`.
- Added protected `GET /tax/reports/detailed`.
- Added `TaxReportsService` using `Bill`, `BillTax`, receipts, and latest
  `TaxCalculationSnapshot` records as report sources.
- Enforced `tax.report_view`/tax read authorization, trusted tenant scope, and
  outlet restrictions.
- Required explicit `tenantId` for platform tax reports.
- Added business-date range handling with a bounded report window.
- Excluded void bills from report totals.
- Audited report generation with `ReportGenerationAudit` and
  `tax.report.generated` audit events.

## Completion Criteria

- Tax summary works.
- Detailed tax report works.
- Outlet filtering works.
- Build passes.
