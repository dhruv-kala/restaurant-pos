# Task 38.2 - Table Self-Service Ordering APIs

## Status

Planned.

## Objective

Allow a valid table session to create customer order requests using menu and
cart validation rules.

## Scope

Implement:

* self-service menu context API
* `SelfServiceOrderRequest` schema
* idempotent order request submission
* backend price/tax/discount validation
* configurable staff approval requirement
* request status APIs

## Deferred

* staff acceptance into final order
* UI
* payments

## Completion Criteria

* Duplicate submissions are prevented.
* Expired or invalid table sessions cannot submit.
* Backend recalculates all commercial values.
