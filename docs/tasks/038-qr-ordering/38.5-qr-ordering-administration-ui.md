# Task 38.5 - QR Ordering Administration UI

## Status

Planned.

## Objective

Add admin and restaurant-app screens for QR ordering profile management, code
rotation, and pending self-service requests.

## Scope

Implement:

* shared Dart QR ordering models
* typed API client
* Riverpod providers
* profile management screen
* table QR code display/rotation screen
* pending request review screen
* accept/reject controls

## Deferred

* printable QR design tooling
* payment terminal pairing
* delivery/pickup screens

## Completion Criteria

* Admin settings support tenant default and outlet override.
* Staff review actions use protected APIs.
* QR tokens are not exposed in logs.
