# Task 38.1 - QR Table Session Foundation

## Status

Planned.

## Objective

Create QR code and table ordering session foundations for customer self-service
at dine-in tables.

## Scope

Implement:

* `QrOrderingProfile` schema
* `TableQrCode` schema
* QR token generation and rotation
* `TableOrderingSession` schema
* session expiry and invalidation rules
* tenant default and outlet override profile evaluation

## Deferred

* self-service order submission
* staff review
* UI
* payment

## Completion Criteria

* QR tokens do not expose tenant internals.
* Sessions are scoped to tenant, outlet, and table.
* QR rotation invalidates old tokens.
