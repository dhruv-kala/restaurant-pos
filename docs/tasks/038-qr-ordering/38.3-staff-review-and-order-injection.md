# Task 38.3 - Staff Review and Order Injection

## Status

Planned.

## Objective

Let authorized staff accept or reject self-service order requests and inject
accepted items into the authoritative order flow.

## Scope

Implement:

* pending request list API
* accept and reject actions
* final order creation/update integration
* kitchen routing trigger through existing order/KDS contracts
* rejection reasons
* audit events

## Deferred

* customer UI
* QR administration UI
* payment collection

## Completion Criteria

* Staff actions require outlet authorization.
* Accepted requests cannot be accepted twice.
* Rejections are visible to customer session status APIs.
