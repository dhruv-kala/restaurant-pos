# Task 39.4 - Fulfillment Capacity and Time Slots

## Status

Planned.

## Objective

Add pickup and delivery capacity windows so outlets can limit order load by
method and time.

## Scope

Implement:

* `FulfillmentCapacitySlot` schema
* capacity evaluation service
* slot reservation on order confirmation
* cancellation/release rules
* protected capacity APIs
* tests for over-capacity rejection

## Deferred

* route optimization
* driver availability
* UI

## Completion Criteria

* Capacity is checked atomically at confirmation.
* Released capacity is traceable.
* Tenant/outlet isolation is enforced.
