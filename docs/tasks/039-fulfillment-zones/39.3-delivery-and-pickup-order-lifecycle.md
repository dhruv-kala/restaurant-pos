# Task 39.3 - Delivery and Pickup Order Lifecycle

## Status

Planned.

## Objective

Create order-linked fulfillment lifecycle records for delivery and pickup
orders.

## Scope

Implement:

* `FulfillmentQuote` snapshot
* `FulfillmentOrder` schema
* `FulfillmentEvent` append-only history
* accept, ready, dispatch, complete, and cancel transitions
* order integration boundaries
* audit events

## Deferred

* capacity slots
* driver tracking
* UI

## Completion Criteria

* Address, fee, and ETA snapshots are immutable after confirmation.
* State transitions are validated.
* Outlet authorization is enforced for staff actions.
