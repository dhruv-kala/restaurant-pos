# Task 29.5 — Redemption and Usage Tracking

## Status

Planned.

## Objective

Track coupon and promotion usage reliably.

## Scope

Implement:

- PromotionRedemption
- coupon usage counters
- customer usage limits
- bill-level redemption history

Do not implement:

- loyalty wallet liability
- referral rewards
- campaign analytics beyond usage summary

## Ownership

- redemption records
- usage counts
- redemption auditability
- duplicate prevention

## Data Model

- PromotionRedemption

## Invariants

- Redemptions are append-only.
- Duplicate redemption is prevented by idempotency.
- Usage limits are enforced before redemption.
- Refunds do not delete redemptions.
- Tenant isolation is enforced.

## Dependencies

Requires:

- Task 29.4
- Billing
- Payments
- Audit

## Completion Criteria

- Redemption records created.
- Usage limits enforced.
- Redemption history available.
- Audit events generated.
- Build passes.
