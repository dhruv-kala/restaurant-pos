# Task 29.2 — Coupon Management

## Status

Planned.

## Objective

Provide coupon code creation, validation, and status management.

## Scope

Implement:

- Coupon
- coupon code validation
- coupon status management
- coupon usage limits foundation

Do not implement:

- full campaign builder
- loyalty rewards
- wallet coupons
- marketing automation

## Ownership

- coupon definitions
- coupon validity windows
- coupon code uniqueness
- coupon usage constraints

## Data Model

- Coupon

## Coupon Types

- percentage
- fixed amount
- free item
- category discount
- item discount

## Invariants

- Coupon codes are unique per tenant.
- Expired coupons cannot be validated.
- Inactive coupons cannot be applied.
- Tenant isolation is enforced.
- Coupon validation does not create redemption records.

## Dependencies

Requires:

- Task 29.1
- Customer Management
- RBAC
- Audit

## Completion Criteria

- Coupons can be created.
- Coupons can be updated.
- Coupons can be validated.
- Invalid/expired coupons are rejected.
- Build passes.
