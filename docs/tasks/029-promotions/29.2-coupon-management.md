# Task 29.2 - Coupon Management

## Status

Complete.

## Objective

Provide coupon code creation, validation, and status management.

## Scope

Implemented:

- Coupon
- coupon code validation
- coupon status management
- coupon usage limits foundation

Not implemented:

- full campaign builder
- loyalty rewards
- wallet coupons
- marketing automation
- redemption tracking
- admin UI

## Ownership

- coupon definitions
- coupon validity windows
- coupon code uniqueness
- coupon usage constraints

## Data Model

- Coupon

## Coupon Types

- percentage
- fixed amount
- free item
- category discount
- item discount

## Invariants

- Coupon codes are unique per tenant.
- Expired coupons cannot be validated.
- Inactive coupons cannot be applied.
- Tenant isolation is enforced.
- Coupon validation does not create redemption records.

## Dependencies

Requires:

- Task 29.1
- Customer Management
- RBAC
- Audit

## Implementation Notes

Completed on 2026-06-14.

- Added tenant-scoped `Coupon` records with optional outlet scope.
- Added uppercase normalized coupon codes unique per tenant.
- Added validity windows, active/inactive status, usage-limit foundation fields,
  and optimistic `version` updates.
- Added coupon types for percentage, fixed amount, free item, category, and item
  discounts.
- Added optional menu category/item/free-item references for future eligibility
  work.
- Added read-only coupon validation that rejects missing, inactive, expired,
  not-yet-active, currency-mismatched, and total-limit-exhausted coupons.
- Added audit events for coupon creation, update, and validation.
- Added coupon RBAC seed entries:
  `promotions.coupon_view`, `promotions.coupon_manage`, and
  `promotions.coupon_validate`.

## Completion Criteria

- Coupons can be created.
- Coupons can be updated.
- Coupons can be validated.
- Invalid/expired coupons are rejected.
- Build passes.
