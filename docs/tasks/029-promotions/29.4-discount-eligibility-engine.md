# Task 29.4 — Discount Eligibility Engine

## Status

Planned.

## Objective

Implement centralized eligibility evaluation for coupons, campaigns, and discount policies.

## Scope

Implement:

- eligibility evaluation service
- rule evaluation
- bill/order/customer context evaluation
- conflict handling foundation

Do not implement:

- AI recommendations
- customer segmentation
- marketing automation

## Ownership

- eligibility checks
- rule evaluation
- discount conflict detection
- stacking rules

## Rule Inputs

- tenant
- outlet
- customer
- order
- bill
- items
- categories
- date/time
- payment method
- customer type

## Invariants

- Eligibility is evaluated centrally.
- Business modules must not duplicate eligibility logic.
- Rules are deterministic.
- Denied discounts return explicit reasons.
- Tenant isolation is enforced.

## Dependencies

Requires:

- Task 29.1
- Task 29.2
- Task 29.3
- Orders
- Billing
- Customer Management

## Completion Criteria

- Eligibility engine works.
- Invalid discounts return reasons.
- Stacking rules are enforced.
- Build passes.
