# Task 37.5 - Customer App Foundation UI

## Status

Planned.

## Objective

Create the customer Flutter app foundation for browsing menu items, managing a
cart, and reviewing a draft order.

## Scope

Implement:

* shared Dart customer ordering models
* typed API client
* Riverpod providers
* customer app routing foundation
* menu browsing screens
* item detail screen
* cart screen
* draft-order review screen

## Deferred

* QR table session UI
* delivery/pickup UI
* online payment checkout
* loyalty expansion

## Completion Criteria

* UI consumes backend contracts only.
* Cart totals are presented as backend-calculated values.
* Flutter analyze passes for changed apps/packages.
