# Task 37.4 - Customer Authentication and Guest Session Foundation

## Status

Planned.

## Objective

Create customer and guest session handling for customer-facing ordering without
granting staff or admin privileges.

## Scope

Implement:

* guest session token contract
* optional customer account association
* session refresh and expiry rules
* customer profile lookup boundary
* consent hooks for future marketing
* tests for privilege separation

## Deferred

* loyalty UI
* wallet
* MFA
* social login

## Completion Criteria

* Guest/customer sessions cannot call staff APIs.
* Customer account links are tenant scoped.
* Expired sessions cannot mutate carts.
