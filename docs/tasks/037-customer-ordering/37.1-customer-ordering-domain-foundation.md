# Task 37.1 - Customer Ordering Domain Foundation

## Status

Planned.

## Objective

Define customer ordering sessions, carts, draft orders, and public context
boundaries before building customer-facing screens.

## Scope

Implement:

* customer ordering setting contract
* `CustomerOrderingSession` schema
* cart and draft-order persistence contracts
* tenant/outlet context resolution
* guest session rules
* idempotency foundation
* permissions for administration

## Deferred

* public menu APIs
* confirmed order submission
* QR ordering
* delivery/pickup
* UI

## Completion Criteria

* Customer ordering state is tenant and outlet scoped.
* Guest sessions cannot access admin data.
* Backend owns all total calculation boundaries.
