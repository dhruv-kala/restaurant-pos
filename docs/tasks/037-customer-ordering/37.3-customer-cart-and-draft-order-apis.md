# Task 37.3 - Customer Cart and Draft Order APIs

## Status

Planned.

## Objective

Add customer cart mutation and backend draft-order validation APIs.

## Scope

Implement:

* cart item add/update/remove APIs
* modifier and add-on validation
* immutable draft-order price snapshot
* tax and discount recalculation
* idempotent draft-order creation
* cart expiration handling

## Deferred

* final order submission
* payment gateway checkout
* QR table flow
* delivery/pickup

## Completion Criteria

* Client-provided totals are ignored.
* Draft orders contain backend-calculated snapshots.
* Invalid menu selections are rejected.
