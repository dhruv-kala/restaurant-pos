# Task 37.2 - Public Menu and Availability APIs

## Status

Planned.

## Objective

Expose customer-safe menu, category, item, modifier, price, and availability
data for a selected tenant/outlet.

## Scope

Implement:

* public menu query service
* customer-safe menu DTOs
* outlet availability filtering
* tenant default and outlet override ordering settings
* tax and promotion preview hooks without committing an order
* public read APIs

## Deferred

* cart mutation
* order confirmation
* QR table sessions
* UI

## Completion Criteria

* Inactive/internal menu data is not exposed.
* Outlet-specific price and availability rules are honored.
* Public APIs cannot enumerate other tenants.
