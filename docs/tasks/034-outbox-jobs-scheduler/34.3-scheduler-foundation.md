# Task 34.3 - Scheduler Foundation

## Status

Complete.

## Objective

Add platform, tenant, and outlet-aware scheduled job definitions that create
background jobs at controlled intervals.

## Scope

Implement:

- `ScheduledJob` and `ScheduledJobRun` schema
- platform, tenant default, and outlet override scheduling scopes
- interval and cron-expression validation
- pause/resume controls
- due-schedule scanner service
- idempotent run creation
- protected scheduler APIs

## Deferred

- visual schedule builder
- external cloud scheduler
- advanced calendars and holidays

## Completion Criteria

- Due schedules create at most one run per due window.
- Paused schedules do not trigger.
- Outlet override schedule behavior is explicit and tenant safe.
- Tests cover due, paused, duplicate, and cross-tenant behavior.

## Completion Notes

Implemented in the NestJS outbox module:

- `ScheduledJob` and `ScheduledJobRun` Prisma models with forced RLS.
- Platform, tenant default, and tenant/outlet override schedule scopes.
- Interval validation and foundation cron validation for minute/hour schedules.
- Protected scheduler APIs for create, list, detail, pause, and resume.
- Due-schedule scanner using locked due rows and idempotent run creation.
- Materialization of scheduled runs into existing `BackgroundJob` records.
