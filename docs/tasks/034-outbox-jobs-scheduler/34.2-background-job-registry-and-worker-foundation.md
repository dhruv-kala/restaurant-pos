# Task 34.2 - Background Job Registry and Worker Foundation

## Status

Planned.

## Objective

Create the backend job registry and worker claim loop required to process
outbox-backed asynchronous work safely.

## Scope

Implement:

* `BackgroundJob` and `BackgroundJobAttempt` persistence
* job type registry and handler contract
* atomic job claim with lease expiration
* job state transitions
* worker batch polling service
* idempotent job creation from outbox events
* tests for claim exclusivity and retryable failures

## Deferred

* cron-like scheduler
* dead-letter administration
* admin UI
* PM2 worker topology

## Completion Criteria

* Workers can claim pending jobs without double execution.
* Attempts are append-only.
* Failed attempts preserve error classification without leaking secrets.
* Tenant scope is preserved from source event to job.
