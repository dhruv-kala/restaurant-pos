# Task 34.5 - Operations Administration UI

## Status

Planned.

## Objective

Add admin operational visibility for outbox events, background jobs, attempts,
schedules, and recovery actions.

## Scope

Implement:

* shared Dart models and typed API client
* Riverpod providers
* admin job dashboard
* job list and detail screens
* attempt history screen
* scheduler list and pause/resume actions
* dead-letter retry/cancel controls

## Deferred

* arbitrary workflow designer
* custom script execution
* mobile restaurant-app UI

## Completion Criteria

* Authorized admins can inspect tenant-scoped jobs.
* Platform operators can inspect platform jobs.
* Manual recovery actions call protected APIs.
* Flutter analyze passes for changed packages/apps.
