# Task 34.4 - Retry, Dead Letter, and Recovery Controls

## Status

Planned.

## Objective

Provide bounded retry, dead-letter, and operator recovery controls for failed
background jobs.

## Scope

Implement:

* retry policy configuration by job type
* next-attempt calculation
* dead-letter transition after retry exhaustion
* manual retry action
* cancellation action
* dead-letter resolution record
* protected recovery APIs
* audit events for manual actions

## Deferred

* UI screens
* alerting integrations
* incident management workflows

## Completion Criteria

* Retryable failures are scheduled with bounded backoff.
* Exhausted jobs become dead-lettered.
* Manual retry and cancel actions are authorized and audited.
* Recovery actions preserve immutable attempt history.
