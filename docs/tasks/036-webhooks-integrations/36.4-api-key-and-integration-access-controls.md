# Task 36.4 - API Key and Integration Access Controls

## Status

Planned.

## Objective

Add tenant-scoped API keys and scoped integration access controls for partner
systems.

## Scope

Implement:

* `IntegrationApiKey` schema
* one-time plaintext key return
* hashed key persistence
* scopes and outlet restrictions
* key authentication guard foundation
* revoke action
* audit events

## Deferred

* OAuth
* partner developer portal
* rate limiting beyond basic guard hooks

## Completion Criteria

* API key plaintext is never stored.
* Revoked keys cannot authenticate.
* Scope and outlet restrictions are enforced by backend guards.
