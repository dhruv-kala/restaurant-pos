# Task 36.5 - Integration Administration UI

## Status

Planned.

## Objective

Add admin screens for integration configuration, credential references,
webhook subscriptions, delivery history, and API keys.

## Scope

Implement:

* shared Dart integration models
* typed API client
* Riverpod providers
* integration list/detail screens
* credential reference workflow
* outbound webhook subscription screens
* API key create/revoke screens
* delivery and inbound event history

## Deferred

* marketplace connector UI
* public developer portal
* custom mapping designer

## Completion Criteria

* UI never displays stored secrets.
* Authorized tenant admins can manage tenant integrations.
* Platform-only provider catalog actions stay separate.
