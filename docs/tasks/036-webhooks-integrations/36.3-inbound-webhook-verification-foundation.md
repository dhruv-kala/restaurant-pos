# Task 36.3 - Inbound Webhook Verification Foundation

## Status

Planned.

## Objective

Create a provider-neutral inbound webhook verification and event persistence
foundation.

## Scope

Implement:

* inbound webhook controller shell
* provider verification adapter interface
* HMAC timestamp verification helper
* replay protection
* `InboundWebhookEvent` history
* sanitized payload persistence
* failure audit events

## Deferred

* marketplace-specific business command handling
* UI
* delivery aggregator integration

## Completion Criteria

* Invalid signatures are rejected.
* Duplicate provider event IDs are ignored safely.
* Raw credentials and sensitive payload fields are not logged.
