# Task 36.2 - Outbound Webhook Subscriptions

## Status

Planned.

## Objective

Allow tenants to subscribe external endpoints to approved domain events through
tenant-safe outbound webhooks.

## Scope

Implement:

* `OutboundWebhookSubscription` schema
* event type allow-list
* signing secret reference
* endpoint validation
* `OutboundWebhookDelivery` append-only history
* enqueue service using Task 34 job infrastructure if available
* protected subscription APIs

## Deferred

* inbound webhooks
* API keys
* admin UI
* marketplace-specific mappings

## Completion Criteria

* Delivery records are append-only.
* Payloads are sanitized.
* Subscription event types are validated.
* Tenant and outlet scope are enforced.
