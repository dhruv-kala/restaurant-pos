# Task 36.1 - Integration Registry and Credential References

## Status

Planned.

## Objective

Create the integration provider catalog and tenant integration configuration
foundation with safe credential references.

## Scope

Implement:

* `IntegrationProvider` platform catalog schema
* `TenantIntegration` schema
* `IntegrationCredential` metadata with environment/secret references
* tenant default and outlet override support
* credential value rejection in metadata
* protected provider and tenant integration APIs
* audit events

## Deferred

* outbound webhooks
* inbound webhook endpoints
* API keys
* admin UI

## Completion Criteria

* Plaintext credentials are not persisted.
* Tenant integration rows are RLS protected.
* Platform catalog writes require platform authorization.
