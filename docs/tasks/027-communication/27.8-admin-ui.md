# Task 27.8 — Communication Center UI

## Status

Complete.

## Objective

Provide tenant administrators with a centralized communication management interface.

## Scope

Implement:

* Communication Dashboard
* Template Management UI
* Message History UI
* Delivery Attempt UI
* Provider Configuration UI

Do not implement:

* marketing campaigns
* customer segmentation
* AI content generation

## Ownership

* communication administration
* template administration
* provider administration
* delivery history visibility

## Screens

### Communication Dashboard

Display:

* messages sent
* delivery success rate
* failed deliveries
* channel usage

### Templates

Display:

* templates
* versions
* preview

### Message History

Display:

* sent messages
* delivery status
* delivery attempts

### Providers

Display:

* configured providers
* provider health
* provider status

## Authorization

Requires:

* COMMUNICATION_VIEW
* COMMUNICATION_TEMPLATE_MANAGE
* COMMUNICATION_PROVIDER_MANAGE

## Dependencies

Requires:

* Task 27.1
* Task 27.2
* Task 27.7

## Completion Criteria

* Dashboard operational.
* Templates manageable.
* History searchable.
* Providers configurable.
* Build passes.

## Implemented

* Permission-aware Communication Center navigation in `apps/admin`
* Operational message totals, success rate, failures, and channel usage summary
* Template search/filter, create, update, immutable version history, and preview
* Searchable message history with channel/status filters and message detail
* Delivery-attempt inspection with provider identifiers and safe error codes
* Provider list, create, update, activation status, priority, and JSON metadata
* Tenant-safe provider administration APIs with optimistic versioning and audit
* Environment-only credential references and embedded-secret rejection
* Shared communication models, typed Dio client, repository, and Riverpod state

Task 27.8 uses existing paginated message totals for the dashboard. Historical
trends, provider latency, failure rates, and reporting remain Task 27.9.
