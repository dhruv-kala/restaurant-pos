# Task 27.9 — Communication Analytics

## Status

Planned.

## Objective

Provide operational visibility into communication effectiveness and provider performance.

## Scope

Implement:

* communication metrics
* delivery reporting
* provider performance reporting
* channel reporting

Do not implement:

* BI exports
* AI recommendations
* campaign attribution

## Ownership

* communication KPIs
* provider metrics
* channel metrics

## Metrics

### Delivery

* total messages
* delivered messages
* failed messages
* success rate

### Channel Usage

* email volume
* SMS volume
* WhatsApp volume
* push volume

### Provider Performance

* average delivery time
* failure rate
* webhook latency

## Reports

* communication summary
* provider performance
* channel performance
* delivery trends
