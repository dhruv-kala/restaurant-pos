# Task 27.2 — Communication Template Management

## Status

Planned.

## Objective

Provide reusable communication templates with immutable versioning and placeholder rendering.

## Scope

Implement:

* CommunicationTemplate
* CommunicationTemplateVersion

Implement:

* template CRUD
* template preview
* template versioning
* variable placeholders

Do not implement:

* provider delivery
* scheduling
* campaigns
* localization engine

## Ownership

* template storage
* template version history
* template rendering

## Data Model

* CommunicationTemplate
* CommunicationTemplateVersion

## Template Variables

Examples:

* {{customerName}}
* {{orderNumber}}
* {{orderTotal}}
* {{rewardPoints}}

## Invariants

* Templates are tenant scoped.
* Versions are immutable.
* Editing creates a new version.
* Existing messages retain original version references.

## API

* GET /communication/templates
* GET /communication/templates/:id
* POST /communication/templates
* PATCH /communication/templates/:id
* GET /communication/templates/:id/versions

## Completion Criteria

* Templates can be created.
* Templates can be versioned.
* Variables render correctly.
* Audit events generated.
