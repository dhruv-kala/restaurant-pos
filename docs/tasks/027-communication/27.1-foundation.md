# Task 27.1 - Communication Infrastructure Foundation

## Status

Implemented on 2026-06-13.

## Scope

- provider-neutral communication channels and lifecycle enums
- tenant-scoped provider metadata, message, and delivery-attempt persistence
  contracts
- forced PostgreSQL row-level security and tenant-aware foreign keys
- protected recipient addressing using ciphertext, SHA-256 lookup hash, and
  masked display value
- message request fingerprints and tenant/channel idempotency
- internal transactional enqueue service
- provider adapter interface
- message and attempt transition rules

## Invariants

- No plaintext provider credentials are stored.
- No plaintext recipient address is persisted by the communication schema.
- Message content snapshots are immutable.
- Delivery attempts cannot be deleted.
- Reusing an idempotency key with different request content is rejected.
- Sensitive metadata is sanitized by communication-owned code before message
  persistence.
- External providers are never called from business modules.
- All communication rows carry tenant scope and forced RLS.
