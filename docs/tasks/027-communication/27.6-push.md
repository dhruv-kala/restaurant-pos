# Task 27.6 — Push Notification Delivery

## Status

Complete.

## Objective

Implement mobile and web push notification delivery.

## Scope

Implement:

* Firebase Cloud Messaging integration
* device registration
* push delivery
* push delivery tracking

## Ownership

* push delivery
* device token management
* delivery tracking

## Supported Use Cases

* order updates
* loyalty alerts
* promotional notifications
* operational alerts

## Delivery Status

* PENDING
* SENT
* DELIVERED
* FAILED

## Invariants

* Device tokens are tenant scoped.
* Invalid tokens are automatically deactivated.
* Push payloads remain immutable after creation.
* Retry logic belongs to later tasks.

## Dependencies

Requires:

* Task 27.1
* Task 27.2

## Completion Criteria

* Push notifications deliver successfully.
* Device registration works.
* Delivery tracking works.
* Audit events generated.

## Implemented Foundation

* Firebase Cloud Messaging HTTP v1 adapter
* OAuth access tokens from environment-referenced service-account JSON or key
  files
* Tenant/user-scoped Android, iOS, and web device registration
* AES-256-GCM token encryption, SHA-256 lookup hashes, and masked responses
* Authenticated list, register, and unregister endpoints
* Immutable notification title, body, and scalar data payload delivery
* Append-only communication attempts and push sent/failed audit events
* Automatic invalid-token deactivation for token-specific FCM errors

FCM provider acceptance maps to local `SENT`. Automatic retries, client SDK
registration wiring, and broader provider callback handling remain deferred.
