# Task 27.4 — SMS Delivery Providers

## Status

Planned.

## Objective

Implement SMS communication delivery through provider adapters.

## Scope

Implement:

* SMS provider abstraction
* SMS delivery execution
* SMS status tracking

Future provider support:

* Twilio
* MSG91
* TextLocal

Initial implementation may use a single provider.

## Ownership

* SMS delivery
* SMS status tracking
* provider execution

## Supported Use Cases

* OTP
* password reset
* order updates
* delivery status
* operational alerts

## Delivery Status

* PENDING
* PROCESSING
* SENT
* DELIVERED
* FAILED

## Invariants

* Provider credentials never appear in logs.
* Phone numbers are validated before delivery.
* Delivery failures create attempts.
* SMS content is stored as immutable snapshots.
* Retry logic belongs to later tasks.

## Dependencies

Requires:

* Task 27.1
* Task 27.2

## Completion Criteria

* SMS sending works.
* Status tracking works.
* Audit events generated.
* Tenant isolation enforced.
